# 📋 Interactive Personal Data Collector

## 📖 Project Description

The **Interactive Personal Data Collector** is a beginner-friendly Python project that demonstrates the use of variables, data types, user input, type conversion, arithmetic operations, and built-in Python functions. The program collects personal information from the user and performs simple calculations before displaying the results.

This project is designed for students learning Python fundamentals.

---

## ✨ Features

- Collects the user's name
- Accepts age, height, and favorite number
- Displays the data type of each input
- Displays the memory address of each variable using `id()`
- Calculates the user's approximate birth year
- Rounds the user's height to the nearest whole number
- User-friendly console interface

---

## 🛠️ Technologies Used

- Python 3
- Built-in Python Functions
- User Input (`input()`)
- Type Conversion (`int()`, `float()`)
- Variables and Data Types
- Arithmetic Operations

---

## 📥 Installation

1. Install **Python 3** on your computer.
2. Download or clone this repository.
3. Open the project folder in your terminal or command prompt.

---

## ▶️ Usage

Run the program using:

```bash
fundamentals of booster.py
```

Follow the on-screen instructions to enter:

- Name
- Age
- Height (in meters)
- Favorite Number

The program will then display the collected information along with the calculated birth year and rounded height.
